Atualização v0.3.0

Copie o conteúdo deste pacote para a raiz do projeto atual e confirme a substituição dos arquivos existentes.
O pacote não contém a pasta .git.

Principais mudanças:
- botão + Nova aula;
- edição de aulas existentes;
- alteração de início/fim e duração;
- campo opcional de sala/laboratório;
- cancelamento lógico;
- histórico local da sessão;
- desfazer criação, edição, cancelamento e movimentação;
- restauração completa da turma para a grade-base;
- impressão/PDF acompanha automaticamente a grade efetiva.

Depois de copiar:

npm install
npm run dev

O npm install não adiciona dependências novas nesta versão; serve apenas para garantir que o ambiente local esteja consistente.
