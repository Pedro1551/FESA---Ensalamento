# Changelog

Todas as mudanças relevantes do projeto serão registradas aqui.

## [0.1.0] - 2026-10-07

### Adicionado
- Estrutura inicial em JavaScript + Vite.
- Importação do arquivo Excel `.xls/.xlsx`.
- Parser automático de cursos, turmas, horários, disciplinas e professores.
- Grade semanal dinâmica.
- Drag-and-drop de aulas.
- Troca entre aulas de mesma duração.
- Validação de conflito de professor entre turmas.
- Desfazer alteração e restaurar turma.
- Destaque visual das aulas modificadas.
- Dados normalizados de contingência para demonstração.
